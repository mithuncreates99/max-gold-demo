# Max Gold Rouen: concept demo

A clickable concept of a mobile site and a salon dashboard, proposed by Mithun to Max Gold Rouen.

**This is not the salon's official website.** Nothing can be booked or paid, and the dashboard figures are sample data. Prices, opening hours and first names come from the salon's public website and Fresha page (20 October 2026).

Live: https://mithuncreates99.github.io/max-gold-demo/

What it shows:

- the mobile site in French and English: the experience, prices, the barbers, reviews and opening hours;
- booking in three taps (service, barber, then the salon's existing Fresha page);
- the "C'est l'heure de votre coupe ?" reminder, a loyalty card and a gift card;
- a weekly report for the salon and a counter poster for Google reviews.

One self-contained HTML file: no build step, no tracking, works offline once loaded.
